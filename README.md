# Tea Rose

Trademark overlap evidence agent, built on Qloo's taste graph for the Qloo Agentic Hackathon 2026.

Paste a complaint or a cease-and-desist letter. The agent works out which legal questions the dispute turns on, measures whether the two brands share purchasers, how famous the senior mark is and where it is actually known, and writes a memo in which every number traces back to a Qloo query.

Status: in development. Setup instructions follow once the first end-to-end run works.
